Türkçe · English
Ad
Computer Architecture and Organization
Amaç
The aim of this course is to teach the basic building blocks and operating principles of computer systems at the hardware level. It is aimed for students to understand the hardware-software interaction by understanding the organization of processor, memory and input/output units.
İçerik
It covers the fundamental concepts of computer architecture, instruction set structure, data paths, processor design, memory hierarchy, input/output systems, and modern processor techniques such as pipelines. It also covers assembly language programming, system performance metrics, parallel processing structures, and contemporary architectural approaches.

Öğrenme çıktıları

  1. Explain the basic components of a computer and the interactions between these components.
  2. Analyze instruction set architecture and addressing modes.
  3. Can write basic level programs in assembly language.
  4. Be able to analyze processor architecture, data path and control unit design.
  5. Evaluate the structure and operation of memory hierarchy and input/output systems.
  6. Gain the ability to measure, interpret and compare the performance of computer systems.
