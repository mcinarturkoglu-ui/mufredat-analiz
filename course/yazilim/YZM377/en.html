Ad
Matlab Programming
Amaç
The purpose of this course is to provide students with basic knowledge and skills in creating graphics and visualizing data using the MATLAB programming language. Students will learn to effectively use MATLAB's graphic tools to analyze, interpret, and present various types of data.
İçerik
This course covers the graphic capabilities of the MATLAB programming language. In addition to basic MATLAB commands, it includes commands and functions for creating graphics, such as 2D and 3D plots, curve and surface plots, scatter plots, bar plots, histograms, and polar plots. Moreover, students will learn how to customize graphics, adjust colors and line styles, and present graphics more effectively using MATLAB's graphic tools.

Öğrenme çıktıları

  1. Students can create, customize, and effectively visualize various types of graphics using MATLAB.
  2. Students can apply basic principles of graphic design in the process of creating graphics and visualizing data.
  3. Students can enhance their data analysis and interpretation skills using graphic tools.
  4. Students can create and customize complex graphics using MATLAB graphic commands and functions.
  5. Students can apply their knowledge and skills in graphic programming to solve real-world problems through practical applications.

Haftalık konular

1Introduction to the basic structural features of MATLAB and its graphics creation tools.
2Data types, variables, operators, and the use of basic MATLAB commands. Creation of initial graphics and basic data visualization.
3Creation of line plots, scatter plots, bar graphs, and histograms in MATLAB.
4Customization of graphics, adjustment of colors, and style properties. Visualization of data sets using different types of graphics.
5Basic principles of graphic design and best practices for data visualization.
6Exploration of color selection, font usage, labeling, and visual hierarchy. Practical examples and applications for effective graphic design.
7Midterm
8Utilization of advanced graphic features in MATLAB: subplots, axis customization, 3D graphics.
9Creation and activation of user-interactive graphics. Making graphics more complex and dynamic.
10The role of graphics in the data analysis process and visualization of statistical information.
11Usage of MATLAB's statistical graphic tools: box plots, distribution plots, qq plots. Analysis and presentation of data sets using graphics.
12Fundamental concepts of graphic programming and coding in MATLAB.
13Automation of graphic creation and creation of reusable code snippets. Dynamic management and customization of graphics through programming.
14Project Presentation
15Final Exam
