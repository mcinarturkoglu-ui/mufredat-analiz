Orijinal bilgi paketi

Türkçe · English
Ad
Introduction to Programming I
Amaç
-Understanding fundamental programming concepts. -Writing computer programs and acquiring basic programming skills. -Gaining skills in analyzing and solving problems through designing basic algorithms. -Effectively using a programming language.
İçerik
Introduction to programming and basic concepts, Algorithm preparation and sample algorithms, Steps to be followed in problem solving. Flow diagrams and sample algorithmic logics, conditional processing algorithms, use of loops in algorithms and sample applications, introduction to the C programming language and getting to know the C compiler, writing the first program. Conditional statements, loop statements and their usage in C programming language. Series. Functions. Pointers. Sending parameters as values and references to functions. Recursive functions. Structures and unions. Operations on Text and Binary files.
Yöntem ve teknikler
The theoretical part of the course is delivered through lecture notes and slides, using an interactive question-and-answer approach. The practical part involves demonstrating and practicing in a computer environment, utilizing various application methods.

None

Öğrenme çıktıları

  1. Explains and utilizes the fundamental concepts of programming.
  2. Analyzes a problem, generates solution methods, and develops an algorithm.
  3. Writes a program in a programming language to provide a solution for a given problem
  4. Uses conditional statements, loop statements, functions, arrays, structs, and pointers in programming.
  5. Analyzes a given algorithm and explains its working logic.
