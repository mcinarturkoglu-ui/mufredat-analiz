Ad
Web Programming
Amaç
The objective of this course is to provide students with fundamental knowledge and skills in client-server based programming, internet programming, web technologies, and developing dynamic web applications using Node.js.
İçerik
Client-Server based programming Fundamental concepts of Internet Programming HTML, CSS, and Bootstrap JavaScript Synchronous and asynchronous programming Callback, promise, and async/await structures Writing back-end applications using Node.js Middleware structure Using the MVC architecture with Node.js Router operations CSRF security measures Authorization processes Using sessions and cookies Using slugify Using EJS for front-end EJS commands Internet programming with MySQL database Database operations using Sequelize Developing sample applications with EJS and Node.js
Yöntem ve teknikler
Lectures Hands-on Laboratory Work Projects
Ön koşul
None
Öğretim dili
Turkish

Öğrenme çıktıları

  1. Design basic web pages using HTML, CSS, and Bootstrap.
  2. Perform synchronous and asynchronous programming with JavaScript.
  3. Understand the fundamental concepts of Node.js and write back-end code.
  4. Implement middleware structure, MVC architecture, and router operations.
  5. Execute CSRF security measures, authorization processes, and manage sessions and cookies.
  6. Perform internet programming with a MySQL database and execute database operations using Sequelize.
  7. Develop web applications using Node.js.
