Orijinal bilgi paketi

Türkçe · English
Ad
Database and Management Systems
Amaç
The aim of this course is to provide students with the theoretical foundations of database systems, to introduce data models, especially the relational model, and to enable them to develop effective data management skills in engineering applications by providing competence in subjects such as data integrity, normalization, query optimization and database design.
İçerik
The Database and Management Systems course covers the structure, models and data management processes of databases at a theoretical level. Within the scope of the course, the relational data model, data independence, data integrity, key concepts, constraints between relations and data modeling techniques (entity-relationship diagrams) are examined in detail. Topics such as normalization processes (1NF, 2NF, 3NF, BCNF), functional dependencies and schema design aim to create data structures in an efficient and consistent manner. Query languages ??(especially SQL and relational algebra) are covered theoretically; query optimization techniques, indexing methods, transactionality, locking, concurrency control and data recovery mechanisms specific to database management systems are discussed. At the end of the course, students are expected to have knowledge enough to interpret and apply different data models and design principles.

Öğrenme çıktıları

  1. Explains the relational data model and basic database concepts.
  2. Models data using entity-relationship diagrams.
  3. Creates a database schema by applying normalization rules.
  4. Performs theoretical analysis of relational algebra and SQL-based queries.
  5. Explain and evaluate transactionality, concurrency, and data recovery processes.
