Ad
Cloud Computing
Amaç
It is aimed to provide a comprehensive understanding of cloud computing technologies and to provide cloud computing-related application, management and security skills.
İçerik
Cloud Computing Fundamentals, Cloud Computing Models, Cloud Computing Architecture, Cloud Computing Security, Cloud Computing Usage and Management, Cloud Computing Application Scenarios
Yöntem ve teknikler
—
Ön koşul
None
Öğretim dili
Turkish

Öğrenme çıktıları

  1. Will be able to understand the basic concepts and working principles of cloud computing.
  2. Will be able to define cloud computing service models (IaaS, PaaS, SaaS).
  3. Will be able to explain cloud computing distribution models (Public, Private, Hybrid).
