Ad
Digital Image Processing
Amaç
The aim of this course is to enable students to learn the basic concepts of digital image processing, to develop solutions to real-world problems by applying different image processing techniques, and to gain the ability to work with image data in engineering problems.
İçerik
The Image Processing course aims to teach the processes of obtaining, processing, analyzing and interpreting digital images theoretically and practically. First, the basic concepts of digital images, pixel-based structure, color spaces, gray level and histogram analysis are introduced in the course. Then, image enhancement techniques (filtering, contrast enhancement, histogram equalization), edge detection algorithms (Sobel, Canny, Laplacian), morphological operations and image segmentation are discussed in detail. Advanced topics such as Fourier transform, frequency domain filtering, denoising and image restoration are also covered. Students develop practical assignments using OpenCV, skimage and similar libraries with the Python programming language. At the end of the semester, a project is carried out that solves a real-world image processing problem and the learned techniques are put into practice.

Öğrenme çıktıları

  1. Explains the structure of digital images and basic processing techniques.
  2. Compares image filtering, edge detection and segmentation methods.
  3. Performs image processing in the frequency domain and analyzes the results.
  4. Performs applied analysis using image processing tools.
  5. Develops and evaluates appropriate image processing solutions for real-world problems.
