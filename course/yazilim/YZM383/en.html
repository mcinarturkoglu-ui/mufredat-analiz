Orijinal bilgi paketi

Türkçe · English
Ad
Functional Programming
Amaç
It presents the functional programming paradigm with the help of the Haskell language by explaining topics such as implementing functional languages, the benefits of the functional programming style, and creating functional programs as a mathematical calculation process.
İçerik
Introduction to functional programming: Haskell programs, use of Hugs, program syntax, expressions, standard libraries, modules, errors and error messages. Data types: Basic types and definitions, pairs, lists, list derivation, polymorphism, overloading, leading expressions. Function definition: Pattern matching, lists and list patterns, primitive eigencalls on lists, function level definitions, function combination, parameter combination, local definitions. Generalization: Calculation patterns on lists, higher order functions, folding and primitive eigencalls, breaking down lists. Type checking: Uniform type checking, polymorphic type checking, type checking and its classes. Algebraic types: Introduction to algebraic types, self-calling algebraic types, polymorphic algebraic types. Abstract data types: Type representations, queues, design, simulation, search trees, sets, relations and graphs. Purposive computing: Purposive evaluation, calculation rules, data-driven programming, parsing expressions, endless lists. Case studies: Huffman codes, coding and decoding, creating Huffman trees. Programming with actions: Input/output basics, recursion and eigencalling, do structure, monads, monadic computation on trees.

Öğrenme çıktıları

  1. Basit problemleri çözmek için temel fonksiyonel teknikleri kullanabilir.
  2. Yüksek dereceli fonksiyonlar tanımlayabilir ve kullanabilir.
  3. Listeler üzerinde herhangi bir çeşit fonksiyon tanımlayabilir.
  4. Yeni veri tipleri tanımlamak için Haskell ilkelerini kullanabilir.
  5. Bir tembel fonksiyonel dilin ana özelliklerini anlayabilir.
  6. Fonksiyonel biçimde giriş ve çıkış işlemlerini yönetebilir.
