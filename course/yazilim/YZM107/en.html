Ad
Introduction to Computer Science
Amaç
This course aims to provide students with an understanding of the fundamental elements of computer technology and equip them with the skills to effectively use them. The focal points of the course include Microsoft Office applications such as Word, Excel, and PowerPoint, along with basic computer hardware. Students will enhance their abilities in document creation, data analysis, and presentation preparation using these applications.
İçerik
Microsoft Word, Microsoft Excel, Microsoft Powerpoint, Basic Computer Hardware

Öğrenme çıktıları

  1. Students will learn the history and fundamental concepts of computer science.
  2. Students will create and edit documents using the Microsoft Word interface and basic menus.
  3. Students will enter data and use basic and advanced formulas in Microsoft Excel.
  4. Students will create and edit new presentations using the PowerPoint interface and menus.
  5. Students will use the Microsoft Visio interface to create basic shapes and diagrams.

Haftalık konular

1Introduction to computer science, history of computer science
2Introduction of computer hardware units, What are Computer Hardware Components? Motherboard Central Processing Unit (CPU) Memory (RAM) Hard Disk and SSD (HDD, SSD) Graphics Card (GPU) Power Supply (PSU) Input/Output Units (Mouse, Keyboard, Monitor) Other Accessories (Webcam, Microphone, Printer) Keyboard usage
3Microsoft Word, Home, File, Insert Menus: Word interface, creating new documents, opening, saving, basic text editing and formatting (bold, italic, underline), adding headings, bullets and numbering, inserting tables, pictures, and shapes.
4Microsoft Word, Layout and Design Menus: Page layout settings (margins, orientation, size), columns, backgrounds, themes, and styles.
5Microsoft Word, References and Mailings Menus: Creating a table of contents, adding footnotes and endnotes, inserting citations and bibliography, mail merge. Review and View Menus: Reviewing documents, adding comments, tracking changes, switching between different views, sharing and protecting documents.
6Microsoft Excel, Introduction, Home Menu and Data Entry: Excel interface, cell formatting, data entry, basic formulas (SUM, AVERAGE, MIN, MAX)
7Midterm Exam
8Microsoft Excel, Veri Analizi ve Fonksiyonlar: Veri sıralama, filtreleme, gelişmiş fonksiyonlar (VLOOKUP, HLOOKUP, IF, COUNTIF, SUMIF)
9Microsoft Excel, Charts and Visualization: Chart types (line chart, pie chart, bar chart), chart formatting, data visualization
10Microsoft Excel, Macros and VBA: Macro recording, basic VBA coding, automation tasks Visual Basic
11Microsoft Excel, Applied Projects and Advanced Usage: Project development, producing solutions for real-life problems, using advanced functions and VBA
12Microsoft Powerpoint, Home, File, Insert Menus: PowerPoint interface, creating a new presentation, adding and editing slides, text boxes and basic formatting, adding images, shapes, and charts.
13Microsoft Powerpoint, Design, Transitions, Animations, and Slide Show Menus: Slide layout and design themes, transition effects, animations, slide show settings, rehearsing and sharing presentations.
14Microsoft Visio, Introduction, Visio Interface and Basic Shapes: Visio interface, creating a new diagram, adding and editing basic shapes, shape formatting. Creating flowcharts, using flowchart symbols, creating and editing organizational charts.
15Final Exam
