Türkçe · English
Ad
Microprocessors and Programming
Amaç
The aim of this course is to provide students with an understanding of the basic components of computer systems, microprocessor architectures and instruction set structures. It is also aimed to provide practical knowledge and skills in assembly language programming and hardware level interaction with input/output units.
İçerik
Fundamental concepts of computer systems, number systems and microprocessor architectures, instruction set architectures, assembly language programming, interfacing with input/output units, interrupts, timers and direct memory access, embedded systems, basic information and applications on FPGA and soft-core processors are included.

Öğrenme çıktıları

  1. Explain the basic components of a computer and the interactions between these components.
  2. Compare instruction set architecture, processor types, and microprocessor architectures.
  3. Can write, compile and run basic level programs in assembly language.
  4. It can interact with I/O units, interrupts, and timers at the hardware level.
  5. Have basic knowledge about embedded systems, FPGA and soft-core processors and can develop applications.
