Ad
Big Data
Amaç
The Big Data course provides students with a broad understanding of the field of big data, improving their skills to effectively design, implement and manage big data systems.
İçerik
It aims to introduce students to big data concepts, technologies and analysis methods and to provide them with basic knowledge and skills in this field. The course primarily includes an introduction to the concept of big data and the basic principles of data science. It teaches how to organize structured data with relational databases and data modeling topics. It discusses how to combine big data sources with data warehousing and integration. Big data processing infrastructures with Hadoop and parallel database systems are introduced. Distributed processing technologies such as MapReduce and Spark are examined. It teaches effective presentation of analysis results with data visualization methods. It introduces the basics of machine learning and covers basic algorithms such as classification, regression, and clustering. Special big data application areas such as natural language processing and information retrieval are covered. In addition, analysis of social network data and presentations of projects

Öğrenme çıktıları

  1. They will be able to understand the importance of big data and how it is used in different areas.
  2. They will be able to display data graphically using tools such as Tableau and Power BI.
  3. They will be able to use popular big data tools such as Hadoop, Spark, Hive, Pig.
  4. They will be able to understand NoSQL databases and big data and data storage and query techniques.
  5. They will be able to use the techniques and algorithms necessary to process and analyze large data sets.
