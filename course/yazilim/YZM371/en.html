Orijinal bilgi paketi

Türkçe · English
Ad
Machine Learning
Amaç
The aim of this course is to enable students to learn the basic concepts of machine learning and different learning methods. As a result of this course, the student will learn which machine learning method is most appropriate to apply to a real-life problem and how to analyze this method in terms of error and complexity. Will be able to create machine learning applications through practical projects and applications. Will be able to extract information by analyzing data sets. They will be able to create real-time working models with current deep learning methods.
İçerik
Fundamentals of Machine Learning. Classification and Regression Problem. Supervised Learning and Unsupervised Learning. Data Preparation. Methods of completing missing data. Feature Extraction. Feature Selection. Feature Reduction. PCA-Principal Component Analysis. Linear Discriminant Analysis (LDA). Model Training and Testing.Bootstrap, Exclusion Cross-validation methods. Model Performance Measures (Metrics). Prediction, Linear regression. Clustering (K-Means). Ensemble Learning. Segmentation with YOLO algorithm. Real-Time Applications with Deep Learning.

Öğrenme çıktıları

  1. Makine öğrenmesi ile ilgili temel kavramsal çerçeveyi kavrar.
  2. Verilen bir veri seti üzerinde her türlü ön işleme işlemini gerçekleştirir.
  3. Verilen bir gerçek dünya problemine uygulanabilecek makine öğrenmesi metotlarının analizini yapar ve bilgisayarda kodlayarak uygular.
  4. Makine öğrenmesi modellerinin performansını ölçmek için kullanılan metrikleri bilir ve yorumlar.

Haftalık konular

1Makine Öğrenmesinin Temelleri, Sınıflandırma ve Regresyon Problemi, Denetimli Öğrenme ve Denetimsiz Öğrenme.
2Veri bilimi için Python programlamaya hızlı bakış.
3Veri Hazırlama, Eksik verileri tamamlama yöntemleri(silme, ortalama, ortanca, mod, knn yöntemleri), Veri Kalitesi ve Ölçüm Metrikleri, Normalizasyon Yöntemleri
4Öznitelik Çıkarımı (Feature Extraction), Öznitelik Seçme (Feature Selection), Öznitelik İndirgeme (Feature Reduction), PCA-Temel Bileşen Analizi, Linear Discriminant Analysis (LDA).
5Modelin İnşası ve Değerlendirilmesi, Model Eğitimi ve Test, Bootstrap, Dışarıda Tutma, Çapraz doğrulama
6Model Başarım Ölçütleri (Metrikleri), Karışıklık Matrisi, TP, TN, FP, FN Doğruluk, Duyarlılık, Özgüllük, Örnek Python kodları ve İncelenmesi, k-NN makine öğrenmesi algoritması üzerinde uygulama
7Tahmin(prediction), Linear regression, Kümeleme (K-Means), Öznitelik Seçme(Feature Selection (Ayrıntılı Bakış), Temel Temizlik, Sarmalayıcı Yöntemler, Filtreleme Yöntemleri, Embedded Metotlar.
8Image Segmentation (Hızlı Bakış), Performans Metrikleri, Örnek Python Kodlarının İncelenmesi.
9Topluluk Öğrenme(Ensemble Learning), Voting, Stacking
10Topluluk Öğrenme(Ensemble Learning), Bagging, Boosting, Python Kodlarının İncelenmesi.
11YOLO algoritması ile segmentasyon, Veri Seti Hazırlama ve Etiketleme, Etiketleme programlarını tanıma ve kullanma (LabelImg, Roboflow vb.)
12YOLO kurulumu, Eğitim ve Test Tespit edilen bölgenin opencv ile kırpılması
13Derin Öğrenme İle Gerçek Zamanlı, Uygulamalar, Dlib Kütüphanesini kullanarak yüz bölgelerin tespit edilmesi ve Croplanması, Gözlerin açık-kapalı olduğunun gerçek zamanlı (real-time) tespit edilmesi, Dlib kütüphanesi ile yapılabilecek proje önerileri üzerine beyin fırtınası.
14Media Pipe kütüphanesi ile gerçek zamanlı uygulama geliştirme, Selfie Segmentation, Hand Landmark Detection, Face Detection, Face Landmark Detection, Gesture Recognition, Interactive Segmentation Pose Landmark Detection, Proje Önerileri ile ilgili beyin fırtınası
