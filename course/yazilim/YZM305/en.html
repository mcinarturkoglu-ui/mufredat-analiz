Ad
Database and Management Systems Lab.
Amaç
The aim of this course is to provide students with a practical understanding of the fundamentals of relational database systems, to develop data query and management skills with the SQL language, and to provide project development experience with database technologies used in real-world applications.
İçerik
The Database and Management Systems Laboratory course aims to teach students database systems in a practical way. Within the scope of the course, students learn to perform data definition (DDL), data processing (DML) and data query (DQL) operations using the SQL language. Basic concepts such as the relational database model, relationships between tables, and the use of primary and foreign keys are covered in practice. Inner/outer join (JOIN) operations on multiple tables, grouping and aggregation functions, subqueries, views (VIEW), user authorization and data integrity topics are supported with laboratory applications. Students apply the knowledge and skills they have acquired in real data scenarios with an application project where they design and develop a database throughout the semester.
Yöntem ve teknikler
Hands-on computer lab Live SQL writing and feedback Small-scale application development Student project presentations Holistic database project at the end of the semester

Öğrenme çıktıları

  1. Explains basic database concepts and creates data structures in the relational model.
  2. Performs data query and editing operations using SQL language.
  3. Implements data integrity, key usage, and table relationships.
  4. Designs appropriate database structures for real world problems.
  5. Develops complex queries and application projects by working with multiple tables.
