Modül A · Ad ve içerik uyumu

ÖlçütDüzeyGerekçe
Düzey uygunluğu 3/3 Konuların derinliği, dersin Lisans düzeyi ve 6. yarıyıl bilgisiyle uyumlu görünmektedir.

orta Amaç–konu uyumsuzluğu · olası sorun
Amaçta belirtilen 'sensörler' konusu, haftalık konularda açıkça yer almamaktadır.

✓ amac “sensörler, emülatörler, ses, resim ve video, harita servisleri ve veritabanlarını içeren uygulamalar geliştirebilmelerini sağlamaktır.”
✓ hafta:1 “Mobil programlama temelleri”
Öneri: Amaçta belirtilen 'sensörler' konusunun haftalık konulara eklenmesi veya bu konunun ders içeriğinde ele alınması gerekmektedir.
orta Çıktı uyumsuzluğu · olası sorun
Öğrenme çıktıları, amaçta belirtilen 'sensörler' ve 'emülatörler' gibi bazı unsurları kapsamamaktadır.
Amaçta geçen 'sensörler' ve 'emülatörler' kavramları, öğrenme çıktıları arasında doğrudan bir beceri olarak ifade edilmemiştir.
✓ amac “sensörler, emülatörler, ses, resim ve video, harita servisleri ve veritabanlarını içeren uygulamalar geliştirebilmelerini sağlamaktır.”
✓ cikti:1 “Mobil programlamaya ait temel kavramları açıklayabilme;”
Öneri: Öğrenme çıktılarına, amaçta belirtilen 'sensörler' ve 'emülatörler' ile ilgili becerileri eklemek gerekmektedir.

Ad
Mobile Application Development
Amaç
The aim of this course is to provide prospective teachers with knowledge about the basic concepts of mobile programming and also to enable them to develop applications including sensors, emulators, audio, image and video, map services and databases using software development tools for mobile programming.

Öğrenme çıktıları

  1. To be able to explain the basic concepts of mobile programming;
  2. Distinguish mobile operating systems and their features;
  3. To be able to use mobile application development tools;
  4. Ability to use audio, image, video, database and location in mobile programming;
  5. To be able to make different designs with mobile programming;
