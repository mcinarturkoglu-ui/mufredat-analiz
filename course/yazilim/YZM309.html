Türkçe · English
Ad
Web Programlama
Amaç
Bu dersin amacı, öğrencilere client-server temelli programlama, internet programlama, web teknolojileri ve Node.js kullanarak dinamik web uygulamaları geliştirme konusunda temel bilgi ve beceriler kazandırmaktır.
İçerik
Client-Sever temelli programlama, Internet Programlama ile ilgili temel kavramlar, Html, CSS ve Bootstrap, JavaScript, Senkron ve asenkron programlama, callback, promise ve async await yapıları, node.js kullanarak back end uygulama yazma, middleware yapısı, mvc mimarisini node.js ile kullanma, router işlmeleri, csrf güvenlik işlemleri, authorize işlemleri, session ve cookie kullanma, slugify kullanımı, front end için EJS kullanımı, EJS komutları, mysql veri tabanı ile internet programlama, Sequilize kullanarak veri tabanı işlemleri, EJS ve node.js kullanarak örnek uygulama geliştirme.

Öğrenme çıktıları

  1. HTML, CSS ve Bootstrap kullanarak temel düzeyde web sayfaları tasarlayabilir.
  2. JavaScript ile senkron ve asenkron programlama yapabilir.
  3. Node.js’in temel kavramlarını bilir ve back-end kodu yazabilir.
  4. Middleware yapısı, MVC mimarisi ve router işlemlerini uygulayabilir.
  5. CSRF güvenlik işlemleri, authorize işlemleri, session ve cookie yönetimini gerçekleştirebilir.
  6. MySQL veri tabanı ile internet programlama yapabilir ve Sequelize kullanarak veri tabanı işlemlerini gerçekleştirebilir.
  7. Node.js kullanarak web uygulamaları geliştirebilir. ingilizcesi nedir
