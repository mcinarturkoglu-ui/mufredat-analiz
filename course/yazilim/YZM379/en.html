Ad
Ruby Programming
Amaç
The objective of this course is to teach students the Ruby programming language, enhance their software development skills, and provide them with the fundamental knowledge and abilities needed to build modern software applications.
İçerik
This course covers the basic structures, data types, control structures, functions, and object-oriented programming principles of the Ruby programming language. Students will learn Ruby's syntax structure, modular programming techniques, and explore real-world scenarios while developing applied projects. Additionally, topics such as creating dynamic web pages, database interaction, and RESTful web services will be examined, along with popular web frameworks like Ruby on Rails.

Öğrenme çıktıları

  1. Students will comprehend and apply the fundamental structures of the Ruby programming language.
  2. Students will grasp the principles of object-oriented programming in Ruby and develop applications.
  3. Students will be able to create dynamic web applications using popular web frameworks like Ruby on Rails.
  4. Students will perform data management operations by interacting with databases using Ruby.
  5. Students will organize large-scale projects using Ruby's modular programming techniques.
