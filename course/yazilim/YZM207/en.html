Türkçe · English
Ad
Logic Circuits
Amaç
The aim of this course is to enable students to understand the fundamentals of digital systems and to gain basic knowledge and skills for digital circuit design and analysis.
İçerik
Fundamental differences between analog and digital systems, number systems and binary coding, semiconductor devices, Boolean algebra and logic gates, gate-level optimization techniques, medium-scale logic circuits, sequential logic circuit design, memory circuits, computer system architecture, programmable logic circuits (PLA, PAL, GAL, FPGA), and digital system design using VHDL and hardware description language.

Öğrenme çıktıları

  1. Explain the basic building blocks of digital systems and their differences from analog systems.
  2. Design and simplify basic logic circuits using Boolean algebra and logic gates.
  3. Can analyze, design and model combinational and sequential logic circuits.
  4. Can design digital circuits with programmable logic elements (PLA, PAL, HAL etc.).
  5. Can program digital circuits with hardware description language using VHDL.
