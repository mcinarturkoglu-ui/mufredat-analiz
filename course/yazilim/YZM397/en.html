Türkçe · English
Ad
Software Project Management
Amaç
This course aims to teach the basic principles, methods and tools of software project management. Students will learn to organize software development activities, manage projects in terms of time, cost and quality, control changes and risks, and effectively manage human resources and communication. Practical skills will be provided using open source tools such as Project Libre.
İçerik
Understanding and Defining Software Project-Software Project Planning- Project Running - Project Closing; Software Metrics and Software Cost Estimation Techniques; Software Risk Management; Project Organizations and Responsibilities; Agile Software Project Management

Öğrenme çıktıları

  1. Ability to define software development processes and activities.
  2. Ability to manage project objectives, time and costs.
  3. Ability to manage changes, risks and quality effectively.
  4. Ability to manage human resources and communication.
  5. Ability to price software projects.
  6. Ability to apply development and management standards.
  7. Ability to manage projects using open source tools such as Project Libre.
